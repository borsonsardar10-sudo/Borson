# FC Brothers

An interactive EA FC squad builder and team rating calculator app inspired by Mr. Believer's Hub and RenderZ.

## Features
- **Custom Formations:** Select from popular formations (4-3-3, 4-2-3-1, 3-4-3, etc.).
- **Player Database:** Search and select players by position, overall rating (OVR), and event card type.
- **Team Stats Calculator:** Automatically calculates total team OVR, chemistry, and rank boosts.
- **Save & Share:** Save your built squad or share your team link with others.

## Tech Stack
- Frontend: HTML, CSS, JavaScript (or React / Tailwind CSS)
- Data Source: JSON database / FC Mobile player API

## Getting Started

### Prerequisites
- Node.js (if using React/npm)
- A modern web browser

### Installation
```bash
# Clone the repository
git clone https://github.com/borsonsardar10-sudo/Borson.git
cd Borson

# Install dependencies (if using Node.js)
npm install

# Start the development server
npm start
```

### Usage
1. Open the app in your browser
2. Select your preferred formation
3. Search for and add players to each position
4. View real-time team OVR, chemistry, and rank calculations
5. Save your squad or share the team link
